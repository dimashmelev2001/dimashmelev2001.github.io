Что это за приложение

Content Factory — личный инструмент автора для чтения статистики собственных каналов. Им пользуется только владелец аккаунтов. Публичной регистрации пользователей нет.

Какие данные Google запрашиваются

Через YouTube Data API (scope youtube.readonly) — сведения о канале и роликах владельца. Через YouTube Analytics API (scope yt-analytics.readonly) — отчёты статистики этих роликов. Доступ только на чтение; приложение не загружает, не изменяет и не удаляет контент.

Как данные используются и хранятся

Данные используются исключительно для анализа собственных роликов владельца. Токены доступа хранятся локально на компьютере владельца и никому не передаются. Данные не продаются, не передаются третьим лицам и не используются для рекламы. Использование данных Google API ограничено практиками, описанными здесь, и соответствует требованиям Google API Services User Data Policy, включая Limited Use.

Как отозвать доступ

В любой момент на странице myaccount.google.com/permissions или удалением сохранённого токена.
